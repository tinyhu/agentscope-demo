## 简介
本快速开始指南帮助你以最短时间内在本地或容器中部署并运行 AgentScope Demo，完成核心对话、工具调用、文档解析、RAG 知识库等体验。项目基于 Spring Boot + AgentScope（Java），默认启用 DashScope 模型流式能力与赛博朋克风格聊天界面。

## 环境要求
- Java 17+（项目中声明为 Java 17）
- Maven 3.9+
- DashScope API Key：通过环境变量注入，用于连接大模型服务

关键依据：
- 版本声明见构建配置；Java 目标版本为 17。
- 应用通过 application.yml 读取模型 API Key，支持从环境变量 DASHSCOPE_API_KEY 注入。
- 启动端口由配置文件定义，注意与实际访问地址一致。

## 本地快速启动
按顺序执行以下步骤：

1. 安装与校验环境
   - 确认已安装 JDK 17+ 与 Maven 3.9+。
   - 检查命令输出符合预期。

2. 获取并配置 DashScope API Key
   - 将你的 DashScope API Key 设置为环境变量。
   - Windows 示例（PowerShell）：$env:DASHSCOPE_API_KEY="your_api_key_here"
   - Linux/macOS 示例：export DASHSCOPE_API_KEY="your_api_key_here"

3. 运行项目
   - 在项目根目录执行：mvn spring-boot:run
   - 启动成功后会打印可用端口信息。

4. 打开浏览器访问
   - 默认启动后，使用浏览器打开 http://localhost:8081
   - 如需修改端口，可在启动时传入参数或在配置文件中设置。

注意
- 端口：默认启动端口为 8081，非 8080。
- API Key：若未正确设置，后续调用模型时会失败。

## 运行与访问
- 后端服务默认监听端口 8081。
- Web 页面地址：http://localhost:8081
- 其他可选端点（需启用对应 Profile）：
  - AG-UI 协议：需在启动时启用 agui profile，并访问 /ag-ui/run
  - A2A 协议：需在启动时启用 a2a profile，暴露 /.well-known/agent-card.json 和 /a2a/jsonrpc

命令行示例
- 默认运行：mvn spring-boot:run
- 指定模式运行（以 agui 为例）：mvn spring-boot:run --spring.profiles.active=agui
- 指定模式运行（以 a2a 为例）：mvn spring-boot:run --spring.profiles.active=a2a

## 配置说明
应用通过 application.yml 集中管理关键配置，包含服务端口、上传大小限制、日志级别，以及 AgentScope 的模型、记忆、会话、知识库、MCP 等开关。

重点项速览
- 服务端口：8081
- 模型 provider 与 name：dashscope / deepseek-v4-flash-0731
- API Key：通过 DASHSCOPE_API_KEY 注入
- 会话存储：内存模式（可切换 Redis/MySQL/PostgreSQL）
- 知识库：默认开启本地自动索引（path 及分割策略）
- MCP：演示服务器默认开启，独立端口

## Docker 容器化部署
如果你已有应用的镜像或使用官方插件打包，可按以下思路容器化运行：
- 基础镜像：选择含有 JDK 17 的镜像
- 暴露端口：8081
- 环境变量：必须设置 DASHSCOPE_API_KEY
- 挂载数据（可选）：会话或上传路径持久化

容器启动示例（概念性，按你的镜像构建流程适配）
- docker run -p 8081:8081 -e DASHSCOPE_API_KEY=your_key agentscope-demo
注意
- 端口映射必须与 server.port 保持一致。
- 生产环境建议结合外部依赖（数据库、对象存储等）进行配置。

## 功能验证步骤
启动完成后，建议依次验证以下能力：

1. Basic Chat（基础对话）
   - 打开 http://localhost:8081
   - 左侧选择一个 “Basic Chat” 智能体
   - 发送任意消息，验证流式响应

2. Tool Calling（工具调用）
   - 选择 “Tool Calling” 智能体
   - 尝试时间、计算、天气相关问题，观察工具调用与结果呈现

3. Task Agent（文档解析）
   - 在输入框区域点击“+”，选择 .docx/.pdf/.xlsx 文件
   - 发送总结/分析请求，观察解析与回答

4. RAG Chat（知识库问答）
   - 将知识文档放入配置的 knowledge 目录后重启或等待索引
   - 切换到 “RAG Chat” 智能体，提问相关主题

5. Bank Invoice（银行发票生成）
   - 选择 “Bank Invoice” 智能体
   - 提供必要字段，触发 Excel/Word 文件生成与下载链接展示

提示
- 如果首次出现空白或错误，优先检查 API Key 是否正确注入、端口是否为 8081。

## 常见问题排查
- 无法访问站点
  - 检查当前 server.port 是否为 8081（否则请使用该端口）
  - 确认防火墙与安全组已放行

- 对话无响应或报认证错误
  - 确认已正确设置 DASHSCOPE_API_KEY
  - 检查是否使用了有效的模型名

- 文件或知识库功能异常
  - 检查 multipart 上传大小限制是否足够
  - 确保 knowledge 目录存在且具备可扫描的文件
  - 如更换存储类型，按分布式状态配置启用相应 profile 并配置连接信息

- 需要额外能力（AG-UI/A2A）
  - 启动时添加对应的 spring.profiles.active
