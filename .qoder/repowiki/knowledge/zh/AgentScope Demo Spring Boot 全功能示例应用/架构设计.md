以 Spring Boot 为运行容器，按职责拆分为十五个子模块：`agent_core` 与 `resources_and_static` 负责从 agents.yml/harness-agents.yml 加载配置并驱动 `AgentFactory`/`HarnessAgentFactory`；`runtime_engine`、`harness`、`multi_agent`、`blackboard_supervisor` 分别承载 ReAct 单代理、Harness、组合编排与 Supervisor 四种运行时；`controllers` 暴露 REST/SSE/Webhook/Hook 端点，委托 `services`（会话/RAG/工作流追踪）后落到各运行时；`tools` 通过 `ToolRegistry` 提供可被任意代理调用的 POJO 工具；`middleware` 作为可插拔拦截链横切所有执行路径；`config_and_models` 通过 Spring Profile 开关 A2A/分布式状态存储/AG-UI/飞书等扩展；`mcp_integration` 启动 MCP 客户端对接外部工具服务器；`schema` 集中结构化输出 DTO。所有分支在 `ChatController` 的 `/chat/send` SSE 端点汇合，由 `AgentEventMapper` 将 AgentScope 事件映射为统一的 JSON SSE 序列供前端消费。
技术栈: Spring Boot 3.5 + Project Reactor + AgentScope 2.0 GA + DashScope，依赖 Apache POI/PDFBox 处理文档，支持 Docker/Local 双文件系统沙箱与 Redis/MySQL/PostgreSQL 分布式状态存储。
