模块以 `cli_anything.agentscope` 为包根，通过 `setup.py` 暴露 `cli-anything-agentscope` 控制台脚本与 `python -m cli_anything.agentscope` 入口。
- 顶层 `agentscope_cli.py`：使用 Click (`@click.group` + 子命令) 构建 `server/agent/session/chat/knowledge/file/skills` 等命令树；每个命令负责解析参数、调用对应 core 层函数并通过 `ReplSkin` 或 JSON 输出结果。
- `core/` 层：按功能划分子模块（`project.py`、`chat.py`、`session.py`、`agent.py`、`knowledge.py`、`upload.py`），对外只提供薄封装函数，内部委托给 `utils.agentscope_backend` 发起 HTTP 请求。
- `utils/agentscope_backend.py`：纯 HTTP 客户端，统一读取 `AGENTSCOPE_BASE_URL` 环境变量并构造 `/api/*` 和 `/chat/send`、`/chat/upload`、`/chat/download`、`/api/knowledge/documents` 等后端接口 URL；SSE 流式响应通过 `iter_lines()` 逐行解析 `event:`/`data:` 片段并以 callback 方式回调事件，支持阻塞收集与实时打印两种模式。
- `utils/repl_skin.py`：提供彩色/表格/状态风格的终端美化输出，被所有 CLI 命令复用。
- `tests/`：基于 `unittest.mock` 直接 patch `requests.get/post/delete`，不依赖真实服务器，验证后端函数行为。
依赖方向单向：CLI → core → utils/backend → requests，core 不感知 CLI 存在，便于单独复用。
