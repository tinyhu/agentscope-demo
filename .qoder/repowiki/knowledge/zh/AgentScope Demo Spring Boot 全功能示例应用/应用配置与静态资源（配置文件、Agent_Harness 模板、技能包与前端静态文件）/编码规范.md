- Agent/Harness 统一以 `config/*.yml` 中 kebab-case `agentId` 键声明，并在 `systemPrompt` 内用 Markdown 描述角色与工作流程。
- 每个 Harness Agent 模板必须包含顶层 `AGENTS.md` 与可选的 `knowledge/`、`skills/`、`subagents/*.md` 结构，便于 `WorkspaceInitializer` 一键复制为工作区骨架。
- Skill 以独立目录组织，根 `SKILL.md` 描述元数据，资源放 `assets/`，脚本放 `scripts/`，由 ToolRegistry 通过 skillId 映射注册。
- YML 配置采用 application.yml + 多 profile 拆分（`application-a2a.yml`、`application-agui.yml`、`application-feishu.yml`、`application-mysql/postgresql/redis.yml`）模式，默认仅加载 `application.yml` 并排除不必要的自动装配。
- 前端 JS 拆分为 `scripts/modules/*.js` 功能模块，配合 `chat.js`、`api.js`、`state.js` 作为入口与状态容器，CSS 也按 `styles/modules/*.css` 模块化拆分。
