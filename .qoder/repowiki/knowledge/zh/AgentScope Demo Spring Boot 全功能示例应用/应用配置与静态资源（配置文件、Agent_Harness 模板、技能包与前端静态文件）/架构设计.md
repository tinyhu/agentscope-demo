该模块是纯资源目录，按用途划分为四个层次：
- 运行时配置层（`config/agents.yml`、`harness-agents.yml`、`mcp-servers.yml` + `application*.yml`）：通过 kebab-case ID 声明所有单 agent、Harness agent、MCP 服务端连接，被 `AgentConfigService` / `HarnessAgentFactory` / `McpClientService` 在启动时解析并注入；`application.yml` 默认排除 DataSource 与 A2A auto-configuration，由 `application-mysql/postgresql/redis/a2a/agui/feishu.yml` profile 按需启用。
- Agent 模板层（`harness-templates/`）：每个子目录是一个可复用的 Harness Agent 蓝图（含 `AGENTS.md`、`knowledge/`、`skills/`、`subagents/*.md`），部署后由 `WorkspaceInitializer` 复制到工作空间根目录供 Harness 运行。
- 技能包层（`skills/`）：遵循 `SKILL.md + assets/ + scripts/` 约定的 Skill 描述与素材（如 `bank_invoice_java` 附带模板 Word/Excel），由 ToolRegistry/SkillRepository 按 skillId 加载。
- 前端资源层（`static/` + `templates/chat.html`）：模块化 JS（`scripts/modules/{chat,debug,knowledge,session,ui,upload,utils}.js` + `api.js`、`state.js`）、CSS、vendor 依赖（highlight.js、marked.min.js、JetBrains Mono / Orbitron 字体）及 AG-UI 入口页面 `agui.html`，通过 Spring Web MVC 暴露给浏览器访问。
