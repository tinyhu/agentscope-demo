模块以 `HarnessAgentService`（Spring @Service）作为入口：接收 `agentId + executionMode` 参数，按 `agentId:MODE` 构建缓存键并复用 `HarnessAgent` 实例，通过 `RuntimeContext.sessionId/userId` 注入会话上下文后调用 `HarnessRuntime.stream()` 返回 Reactor `Flux<Map<String,Object>>` SSE 流。
- 实例装配由 `HarnessAgentFactory`（@Component）完成：读取 `HarnessConfig`，解析模型（经 `ModelFactory`）、按 `dockerMode` / `isBuilder` 选择文件系统（`FilesystemSpecFactory` 产出 Docker 或 Local），依次装配 compaction、tool result eviction、Plan Mode、Task List、Layered Memory、Permission Context、Skill Repository 及 additional context 等能力。
- 执行层 `HarnessRuntime` 实现 `StreamingAgentRuntime`，统一复用 `AgentEventMapper` 把 AgentScope 2.0 的 `agent.streamEvents()` 转换为本项目统一的 SSE Map 流，并以固定 `done` 事件收尾；ObservabilityHook 挂在运行时上用于可观测性。
- 依赖注入对象集中解耦：`FilesystemSpecFactory` 封装 Local/Docker 沙箱默认参数（镜像、内存、CPU、环境变量）；`CompactionConfigFactory` 统一产出 `CompactionConfig` 与 `ToolResultEvictionConfig`；`WorkspaceInitializer` 负责从 classpath 中 `harness-templates/` 资源复制 agent/subagent 目录到工作区（幂等）。模块与外部仅通过 `AgentConfig`/`AgentConfigService`/`ModelFactory`/`PermissionContextFactory` 等接口交互，不直接持有应用级 Spring 容器。
- 测试覆盖服务缓存键策略、userId 默认值、runtime 事件映射以及工作区初始化行为。
