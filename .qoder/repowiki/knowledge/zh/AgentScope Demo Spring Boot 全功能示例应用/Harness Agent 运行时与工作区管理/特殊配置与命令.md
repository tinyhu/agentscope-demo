工作区初始化强依赖 classpath 下 `src/main/resources/harness-templates/<agentName>/...` 模板资源，首次启动会复制到 `System.getProperty("java.io.tmpdir")` 下的 sandbox/workspace 目录；缺少模板文件时会创建空占位文件保留目录结构。API Key 必须在 `agentscope.model.dashscope.api-key` 或 `DASHSCOPE_API_KEY` 二选一配置，否则 `createStreamFlux` 会抛 `IllegalStateException`。
