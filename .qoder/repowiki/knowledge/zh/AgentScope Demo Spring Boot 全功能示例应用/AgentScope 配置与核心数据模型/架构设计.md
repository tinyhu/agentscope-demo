模块按职责分为两类：
- `config/`：基于 Spring `@Configuration` + `@Profile` 的条件装配块。每个特性以独立配置类组织（如 `A2aServerConfig` 通过 `--spring.profiles.active=a2a` 暴露 ReActAgent.Builder 供 A2A starter 自动装配；`DistributedStateStoreConfig` 用嵌套 profile 为 redis/mysql/postgresql 提供 `AgentStateStore`；`AguiConfig`、`FeishuChannelConfig`、`CorrectSkillDiagnostic` 同理）。非激活的 profile 不会产生 bean，对默认启动零影响。
- `model/`：纯数据类（POJO / Lombok @Getter），面向前端 SSE 和 JSON 序列化。包含请求体 `ChatRequest`（支持多模态内嵌 `ImageFile`/`AudioFile`）、事件载体 `ChatEvent`（`done`/`error` 工厂构造 + `@JsonInclude(NON_NULL)`）、转录消息 `ChatMessage`、审批/会话/快照、索引状态以及统一的模型创建入口 `ModelFactory`（封装 `ModelRegistry.resolve`，自动给裸模型名加 `dashscope:` 前缀并以 `DashScopeChatFormatter` 注册）。`model/` 不依赖 `config/`，仅被上层运行时与控制器消费；测试位于 `src/test/java/com/skloda/agentscope/model/`，覆盖模型字段默认值、无参构造 Bean 绑定及可选字段空值行为。
