- 每个工具方法使用 AgentScope 的 `@Tool(name=..., description=...)` 注解声明对外暴露的工具名与说明，参数统一通过 `@ToolParam(name=..., description=...)` 标注并作为 String/Number/Integer 等基础类型。
- 工具类可以是普通 POJO，由 `ToolRegistry` 构造时通过反射实例化；需要 Spring 注入时使用 `@Component` + `@Value`（如 `WebSearchTool` 的 API Key）。
- 文件解析/生成工具将产物写入 `${java.io.tmpdir}/agentscope-uploads/` 目录，输出文件名通过脱敏后的姓名加日期流水号组合命名（见 `generateFileName`）。
- IO 相关异常（如模板缺失、读取失败）统一捕获后返回 JSON 字符串 `{"success":false,"error":"..."}` 或以 `Error: ...` 开头的错误消息，不向调用方抛出原始异常。
- 测试统一使用 JUnit Jupiter（`org.junit.jupiter.api.Test`），直接 `new XxxTool()` 构造对象并断言返回值或生成的临时文件路径存在。
