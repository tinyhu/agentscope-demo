该模块由三个独立的领域 DTO 类构成，位于 `com.skloda.agentscope.schema` 包下：`ContractMetadata`（包含嵌套的 `ClauseItem`/`RiskItem` 内部类，描述合同条款与风险）、`IDCardData`（身份证基本信息）、`InvoiceData`（发票信息及嵌套的 `InvoiceItem` 行项目）。每个类仅提供公共字段与无参构造器，作为 AgentScope 结构化输出的纯数据载体；它们被上游 tool/harness 层引用，并由 Agent 框架在 LLM 响应中序列化为 JSON 后反序列化回对象，从而在不引入额外 ORM/序列化配置的情况下完成跨进程的数据契约。测试用例按一一对应文件放置在 `src/test/java/.../schema/` 下。
