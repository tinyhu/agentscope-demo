运行 MCP Demo Server 需在 PATH 中存在 Node.js，应用启动时会通过 `npx -y supergateway --stdio 'npx -y @modelcontextprotocol/server-everything'` 拉起两个子进程（默认 SSE 9090、HTTP 9091），可通过 `agentscope.mcp.demo.enabled`、`...demo.sse-port`、`...demo.http-port`、`...demo.startup-timeout` 配置开关与超时；关闭需等待 `PreDestroy` 中进程 `destroy()` + 最多 5s 优雅退出后 `destroyForcibly()`。
