- 所有配置类统一使用 Lombok 的 `@Data` + `@NoArgsConstructor`，按用途叠加 `@AllArgsConstructor` 或 `@Builder`，用于被 SnakeYAML 及单元测试构造。
- 通过 `@Value` 注入布尔开关与端口/超时等参数，并在 `@PostConstruct` 中以 `if (!enabled) { log.info(...); return; }` 的守卫模式实现可选组件启用。
- 传输适配采用 switch/case 枚举分支配合独立 configureXxx 私有方法（STDIO→`configureStdio`，SSE/HTTP→各自方法），未知类型记录 warn 并跳过。
- 对外生命周期资源管理统一在 `@PostConstruct` 初始化、`@PreDestroy` 中遍历集合逐一 close/destroy，异常用 warn/log 记录而非中断流程。
- HTTP header/queryParam 值统一经过 `resolvePlaceholders` 解析 `${ENV_VAR}` / `${ENV_VAR:default}` 占位符后再写入 `McpClientBuilder`。
