- 文档标题使用 Markdown H1 写明主题，并在正文开头以「日期 + 项目 + 状态行」声明当前所处阶段（例如「状态: 已实现 / 设计完成，待实施」）。
- 每个特性同时维护 specs/ 与 plans/ 两套平行文件，spec 聚焦「做什么与为什么」，plan 聚焦「改哪些文件、分几个 Task、验证方式」。
- 文件名强制使用 `YYYY-MM-DD[-pX-]主题.md` 格式，其中 pX 表示 P0~P6 优先级，便于按时间与优先级双轴检索。
- Plan 类文档以任务化 check-list 和表格（文件/责任/改动）组织变更范围，并在末尾明确「明确不做」的 Roadmap 积压项，划定本次改动边界。
