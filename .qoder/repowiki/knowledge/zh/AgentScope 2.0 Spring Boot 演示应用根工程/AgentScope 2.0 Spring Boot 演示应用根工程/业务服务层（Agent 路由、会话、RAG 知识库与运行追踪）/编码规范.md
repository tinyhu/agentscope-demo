- 服务类使用 Lombok `@Getter`/`@Setter` 与 Spring `@Service`/`@Repository` 标注，字段通过构造函数注入并使用 `@Autowired(required = false)` 标记可选依赖（如 `SupervisorRuntimeFactory`）。
- 易变共享状态统一使用 `ConcurrentHashMap` 配合原子类型（`AtomicBoolean`、`AtomicLong`）实现无锁或多粒度同步，避免全局阻塞。
- 长生命周期资源（背景索引器 `ExecutorService`、会话 context）通过 `@PreDestroy`、`finally` 块与 `shutdown()/awaitTermination()` 确保关闭释放。
- 外部系统调用失败路径集中抛出包装后的 `RuntimeException`（如 `Failed to index document`、`Unsupported file type`），并先更新内部 `KnowledgeFileStatus.State` 再 throw。
- 配置驱动开关通过 `@Value` 或 `@ConfigurationProperties(prefix = "agentscope.knowledge|agentscope.model")` 注入，默认值直接写在属性/注解中以便热插拔。
