本模块封装对 AgentScope `io.agentscope.core.tool.mcp` 的调用，围绕三个核心职责组织：
- 配置模型层：`McpTransport` 枚举（STDIO/SSE/HTTP）定义传输类型；`McpServerConfig` 聚合命令、URL、header/queryParams、超时等参数；`McpServersWrapper` 作为 YAML 根容器承载多个 `McpServerConfig`；`McpServerRef` 与 `ToolGroupConfig` 表达“服务器到工具集的映射与分组”。
- 客户端服务层：`McpClientService`（Spring @Service）在 `@PostConstruct` 中通过 SnakeYAML `Constructor(McpServersWrapper.class, ...)` 将 `classpath:config/mcp-servers.yml` 反序列化为配置对象，再依据 `transport` 分派至 `configureStdio/configureSse/configureHttp`，用 `McpClientBuilder` 构建并缓存到 `ConcurrentHashMap` 中，对外暴露 `getClient(serverName)` / `getAllClients()` / `isActive()`。
- 本地 Demo 进程层：`McpDemoServer`（Spring @Component，受 `agentscope.mcp.demo.enabled` 控制）通过 `ProcessBuilder` 启动两个 `supergateway` 子进程分别以 SSE 与 streamable-http 模式桥接 `@modelcontextprotocol/server-everything`，使用 `Socket` 轮询端口就绪并提供 `getSseUrl/getHttpUrl` 等便捷访问方法。
依赖方向：`McpClientService` → `McpTransport` + `McpServerConfig` + AgentScope `McpClientBuilder`；`McpDemoServer` 仅通过系统 `node/npx/supergateway` 进程接口与服务端解耦，两者不互相依赖，由上层装配入 Spring 容器（且 `McpClientService` 通过 `@DependsOn("mcpDemoServer")` 确保 demo 先启动）。
