- Web 层统一通过构造器注入 service 依赖（`AgentService`、`WorkflowRunService`、`KnowledgeService`、`ApprovalService` 等），避免字段级 `@Autowired` 散乱使用（`KnowledgeController` 外均走构造器）。
- 外部错误通过 `onErrorResume` 将异常转换为结构化的 SSE event（`ChatEvent.error`）并以 `type=error` 结尾，确保前端可消费一致的终止事件。
- SSE 事件统一经 `ServerSentEvent.builder().event(SSE_EVENT_NAME)` 包装，并通过常量 `SSE_EVENT_NAME = "message"` 集中管理事件名。
- 对非关键异常采用「返回 ok 空体」策略（如飞书 webhook 解析失败返回 `ResponseEntity.ok(\"{}\")`），避免破坏第三方回调约定。
- REST 资源访问统一使用 `@RequestMapping` 前缀分组（`/api/workflows`、`/api/knowledge`、`/api/metrics`）并以简洁路径动词命名具体操作。
- 条件装配通过 `@Profile("feishu")` 控制组件是否参与上下文，使渠道能力按需启用而不影响主进程。
