本模块为表现层控制器集合，按业务域拆分为五个独立 Controller：
- `ChatController`：核心对话入口，通过 `AgentService.createStreamFlux` 返回 `Flux<ServerSentEvent<String>>` 实现 SSE 流式响应，并集成 HITL（Human-in-the-Loop）审批端点 `/chat/approve`，使用 `ApprovalService` + `AgentRuntime` 恢复暂停的 agent；文件上传通过 multipart 暂存到 `{java.io.tmpdir}/agentscope-uploads`。
- `KnowledgeController`：以 `@RestController` 暴露 `/api/knowledge`，封装文档上传（限制 pdf/docx/txt/md）、索引状态查询与 RAG 检索调用 `KnowledgeService.retrieve`，复用 `io.agentscope.core.rag.model.Document`（标注 @Deprecated 以便后续替换）。
- `WorkflowController`：基于 `WorkflowRunService` 暴露工作流运行快照查询 `GET /api/workflows/*`，用 `Optional` 转 404。
- `FeishuChannelController`：标记 `@Profile("feishu")` 仅在飞书模式激活，消费飞书事件回调 `/channel/feishu/webhook`，处理 URL challenge、encrypt 解密、`InboundMessage` 映射，并将结果通过 `FeishuOutboundClient` 回写；依赖 `agentscope-extensions-channel-feishu` 扩展包。
- `MetricsController`：调试用的审计指标端点 `POST /api/metrics/print|reset`，直接驱动 `MetricsCollectorMiddleware`。
依赖方向单向向外：所有 controller 仅依赖 service/runtime/harness，不反向引用，入参统一通过请求体或路径参数注入，返回体为 POJO 或 `Map<String,Object>` 兼容消息协议。
