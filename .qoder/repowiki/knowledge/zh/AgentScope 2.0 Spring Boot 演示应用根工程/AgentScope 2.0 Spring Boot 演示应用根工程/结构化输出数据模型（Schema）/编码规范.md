- 每个 schema 类都提供公共字段声明和一个显式的无参构造器，以便 JSON 反序列化器（如 Jackson）通过反射实例化。
- 需要聚合多值的复杂结构以嵌套静态内部类表示（如 `ContractMetadata.ClauseItem`、`InvoiceData.InvoiceItem`），保持外层 DTO 的扁平字段列表。
- 枚举式约束通过字段的注释形式标注（如 severity/currency/category 的取值说明 `// LOW, MEDIUM, HIGH, CRITICAL`），而非使用 Java enum 或 `@Pattern` 校验。
- 类级 Javadoc 统一以「Structured output schema for ...」开头，明确其作为 AgentScope 结构化输出契约的定位。
