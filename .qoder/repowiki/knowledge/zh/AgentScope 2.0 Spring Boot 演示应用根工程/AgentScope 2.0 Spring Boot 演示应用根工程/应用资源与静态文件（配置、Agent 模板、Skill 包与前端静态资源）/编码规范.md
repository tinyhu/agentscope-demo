- Agent/Harness 统一在 `config/*.yml` 中以 kebab-case `agentId` 键声明，并在 `systemPrompt` 内用 Markdown 描述角色、工作流程与输出格式。
- 每个 Harness Agent 模板必须包含顶层 `AGENTS.md` 以及可选的 `knowledge/`、`skills/`、`subagents/*.md` 结构，便于 `WorkspaceInitializer` 一键复制为工作区骨架。
- Skill 以独立目录组织，根 `SKILL.md` 描述元数据，资源放 `assets/`，脚本放 `scripts/`，由 ToolRegistry 通过 skillId 映射注册。
- YML 配置采用 `application.yml` + 多 profile 拆分模式，默认仅加载基础配置并排除不必要的自动装配，特定能力通过 `application-*.yml` 按需启用。
- 前端 JS 拆分为 `scripts/modules/*.js` 功能模块，配合 `chat.js`、`api.js`、`state.js` 作为入口与状态容器，CSS 也按 `styles/modules/*.css` 模块化拆分。
