该模块为纯资源目录，按用途划分为五个层次：
- 运行时配置层：`application.yml` 定义默认模型（DashScope deepseek-v4-flash）、内存/RAG/MCP 等全局设置，并通过 `spring.autoconfigure.exclude` 默认禁用 DataSource 与 A2A 自动装配；`application-a2a.yml`、`application-agui.yml`、`application-feishu.yml`、`application-mysql.yml`、`application-postgresql.yml`、`application-redis.yml` 以 Spring profile 按需启用对应能力。
- Agent 注册层：`config/agents.yml`、`harness-agents.yml`、`mcp-servers.yml` 以 kebab-case `agentId` 声明单 Agent、Harness Agent（含 `harnessConfig.executionMode`/`plan`/`compaction`）与 MCP 服务端连接，由 `AgentConfigService` / `HarnessAgentFactory` / `McpClientService` 在启动时解析注入。
- Agent 模板层：`harness-templates/<name>/` 每个子目录是一个可复用的 Harness Agent 蓝图，包含顶层 `AGENTS.md`、可选 `knowledge/`、`skills/`、`subagents/*.md`，部署后由 `WorkspaceInitializer` 复制到工作区根目录供 Harness 运行。
- 技能包层：`skills/<skillId>/` 遵循 `SKILL.md + assets/ + scripts/` 约定组织 Skill 描述与素材（如 `bank_invoice_java` 附带 Word/Excel 模板），由 ToolRegistry/SkillRepository 通过 skillId 加载。
- 前端资源层：`static/` 提供模块化 JS（`scripts/modules/{chat,debug,knowledge,session,ui,upload,utils}.js` + `api.js`、`state.js`）、CSS（`styles/modules/*.css`）、vendor 依赖（highlight.js、marked.min.js、字体）及 AG-UI 入口 `agui.html`，配合 `templates/chat.html` 经 Spring Web MVC 暴露给浏览器访问。
