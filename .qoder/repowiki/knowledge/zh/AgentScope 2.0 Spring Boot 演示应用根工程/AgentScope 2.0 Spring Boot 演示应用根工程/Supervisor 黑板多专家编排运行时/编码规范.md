- 跨专家共享状态统一建模为 `State` 实现的 `SessionBlackboard`，并以 per-(userId,sessionId) slot 存储在底层 `AgentStateStore` 中。
- 专家只能产出不可变的 `BlackboardPatch`，真正的合并与版本递增仅由 `BlackboardService.applyPatch` 在单 slot 锁内执行（唯一写者协议）。
- 所有对外暴露的可变集合均通过构造函数或 getter 做深拷贝/`Collections.unmodifiableMap/List` 包装，防止调用方直接篡改内部状态。
- 并发控制采用 per-slot `ReentrantLock`（实例字段或静态 Map 缓存），对同一 `(userId,sessionId)` 串行化操作，不同 slot 并行执行。
- 纯函数服务类（`RoutingDecisionService`、`BlackboardPatch` 等）不持有会话态，全部通过方法参数显式传入黑板快照与配置。
- SSE 事件流遵循固定生命周期：`supervisor_start` → 逐条 `routing_event`/中间事件 → 末尾 `done`，异常路径补发 `error` 类型事件。
