- 对 `HarnessAgent` 实例按 `agentId:executionMode.toUpperCase()` 组合键在 `ConcurrentHashMap` 中缓存，确保同一 agent+模式只创建一次。
- 配置文件来源采用 `application.yml` 属性 + `System.getenv()` 回退的双重读取模式（如 API Key 优先读 `agentscope.model.dashscope.api-key`，其次 `DASHSCOPE_API_KEY`）。
- 对外暴露的能力通过独立 Factory 组件封装默认值（`FilesystemSpecFactory`、`CompactionConfigFactory`），由 `HarnessAgentFactory` 按需组装 `HarnessAgent.Builder`。
- 所有 AgentScope 事件流统一经 `AgentEventMapper.apply` 转换后用 Reactor `.handle(...)` 过滤空结果，并以硬编码 `{type:"done"}` 结尾，保证前端统一消费协议。
- 日志使用 SLF4J `LoggerFactory.getLogger(...)` 静态字段声明，关键装配步骤（filesystem 模式、compaction、plan mode、memory、permission、skill repo）均记录带 agentId 的 INFO 行以便追踪。
- 工作区操作一律通过 `WorkspaceInitializer.initializeFromTemplates` / `initializeSubagentWorkspace` 触发，并在每次写入时先 `Files.createDirectories` 再 `REPLACE_EXISTING` 复制，确保幂等可重入。
