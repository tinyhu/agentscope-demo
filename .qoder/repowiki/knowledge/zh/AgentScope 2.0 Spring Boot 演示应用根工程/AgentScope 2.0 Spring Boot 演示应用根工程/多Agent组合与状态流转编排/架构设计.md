模块以 Spring `@Component` 的 `CompositeAgentFactory` 为入口，统一对外暴露三类创建方法：`createSingleAgent*`（委托 `AgentFactory`）、`createRoutingAgent`（通过 `SubAgentTool` 注册子代理为可调用工具，实现动态分发）和 `createStateGraphAgent`（构造 `OrderFulfillmentGraph`）。`graph` 子包内的 `OrderFulfillmentGraph` 是一个自包含的状态机：维护当前状态、持有各 `StateConfig` 对应 `ReActAgent`，执行时根据 LLM 回复中的「决策:xxx」或用户文本事件匹配 `StateTransition`，并在每次 agent 调用/状态迁移时通过 `BiConsumer` 事件消费者派发 `graph_agent_call`、`graph_transition` 等事件。依赖方向单一向下：工厂依赖 `agent.*`、`model.*`、`middleware.*` 与框架类 `io.agentscope.core.*`，状态机不反向依赖工厂；测试位于同包内使用 JUnit5 + Reactor `StepVerifier` 校验状态迁移与事件消费。
