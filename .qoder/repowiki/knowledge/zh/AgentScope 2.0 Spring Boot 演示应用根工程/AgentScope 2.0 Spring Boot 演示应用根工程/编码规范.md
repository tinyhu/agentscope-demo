- 新增 Agent 先在 `config/agents.yml` 或 `harness-agents.yml` 中以 kebab-case ID 定义，再交由工厂实例化，无需重启代码改动。
- 工具统一使用 `@Tool(name, description)` + `@ToolParam` 注解的 POJO，并在 `ToolRegistry` 中注册以被任意代理发现。
- 中间件继承 `MiddlewareBase` 实现拦截逻辑并通过 Spring @Component 自动接入全局中间件链。
- 可选集成（A2A、分布式状态存储、AG-UI、飞书）通过 `@Profile` 条件配置类隔离启用。
- SSE 事件统一经 `AgentEventMapper` 转换为 Map 序列，控制器不再直接暴露 AgentScope 原始事件类型。
- HTTP 控制器返回 `Flux<ServerSentEvent<String>>` 实现响应式流式 SSE，而非同步阻塞响应。
