- Spring 条件装配采用「一个特性 = 一个 `@Configuration` + 顶层 `@Profile(...)`」形式，bean 方法上再用更细粒度的 `@Profile` 区分具体后端（如 `DistributedStateStoreConfig` 中 redis/mysql/postgresql）。
- 不可变 DTO（如 `ChatEvent`）通过私有构造函数 + 静态工厂方法（`done()`、`error(...)`）对外提供构造入口，避免外部直接实例化。
- SSE 事件类使用 Lombok `@Getter` 配合 Jackson `@JsonInclude(JsonInclude.Include.NON_NULL)` 抑制空字段输出，保持 payload 精简。
- 请求体 DTO（如 `ChatRequest`）保持可空字段默认 `null`，并提供默认值注入点（如 `agentId = "chat.basic"`），由单元测试验证默认值与缺失字段行为。
- 跨模块配置值通过 `@Value("${...:default}")` 读取并设置默认值（如 `apiKey`、Redis URL、DataSource 属性），未命中时交由下游 provider/env 回退。
