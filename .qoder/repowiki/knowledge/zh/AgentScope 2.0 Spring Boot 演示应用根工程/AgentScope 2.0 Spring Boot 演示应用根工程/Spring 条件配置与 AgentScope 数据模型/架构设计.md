模块按职责划分为两个并列子包：
- `config/`：全部为 Spring `@Configuration` + 顶层 `@Profile(...)` 的条件装配块，非激活 profile 不产生任何 bean，对默认启动零影响。典型模式如 `A2aServerConfig`（`@Profile("a2a")`，暴露 `ReActAgent.Builder` 供 A2A starter 自动装配）、`DistributedStateStoreConfig`（顶层 `@Profile({"redis","mysql","postgresql"})`，内部再用方法级 `@Profile` 区分具体后端并分别注册 `DataSource` 与 `AgentStateStore`）、以及 `AguiConfig`、`FeishuChannelConfig`、`CorrectSkillDiagnostic`、`JarEnvironmentDiagnostic`、`SkillFileSystemHelperDiagnosticRunner`。
- `model/`：纯数据类，被上层运行时与控制器消费，不依赖 `config/`。核心是 `ModelFactory`（`@Component`），封装 `io.agentscope.core.model.ModelRegistry.resolve`，自动给裸模型名加 `dashscope:` 前缀并以 `DashScopeChatFormatter` 注入上下文；其余类（`ChatRequest`、`ChatEvent`、`ChatMessage`、`MultiModalMessage`、`SessionInfo`、`PendingApproval`、`WorkflowRunSnapshot`、`KnowledgeFileStatus`、`KnowledgeIndexStatus`、`ApprovalRequest`）均为面向前端 SSE 与 JSON 序列化的 DTO。
依赖方向单向：`config/` 可引用 `model/`（如 `A2aServerConfig` 通过 `ModelFactory.createModel`），`model/` 不反向依赖 `config/`。测试位于 `src/test/java/com/skloda/agentscope/model/`，覆盖字段默认值、无参构造 Bean 绑定及可选字段空值行为。
