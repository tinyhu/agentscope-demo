模块以 `ToolRegistry`（Spring @Component）为唯一装配中心，按三阶段完成工具加载：Phase A 使用 `ClassPathScanningCandidateComponentProvider` 扫描 `com.skloda.agentscope.tool` 包下所有类，通过反射查找 `@Tool` 注解方法名并注册；Phase B 扫描 AgentScope 内置 `io.agentscope.core.tool.file` 与 `coding` 包的系统工具；Phase C 从 `classpath:skills/*/SKILL.md` 解析 YAML frontmatter 动态注册技能到工具的映射。工具类本身是普通 POJO（非必须 Spring Bean），参数校验、业务逻辑与 IO 操作集中在每个实现类内：`SimpleTools` 提供演示型时间/天气/计算工具；`PdfParserTool` / `DocxParserTool` / `XlsxParserTool` / `ContractReviewReportTool` 基于 Apache PDFBox/POI 解析或生成 Office/PDF 文件；`WebSearchTool` 封装 Tavily 搜索引擎并通过 Mono+RestTemplate 异步调用；`BankInvoiceTool` 根据 classpath 中 `skills/bank_invoice_java/assets/*` 模板生成 XX 银行发票 Excel/Word 并写入 `${java.io.io.tmpdir}/agentscope-uploads`。测试采用 JUnit Jupiter，直接实例化工具类进行单元测试，覆盖必填校验及文件产出断言。
