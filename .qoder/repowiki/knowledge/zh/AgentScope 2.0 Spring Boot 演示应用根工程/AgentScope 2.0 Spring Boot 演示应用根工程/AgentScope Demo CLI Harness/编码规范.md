- 每个 CLI 子命令采用统一的错误处理模式：先 try/except 调用 core 方法，再根据 `ctx.obj['json']` 决定走 `_json_out` 或 `_skin.*` 格式化输出。
- HTTP 后端函数均以 `base_url` 可选参数形式允许覆盖默认服务地址，同时统一从 `os.environ['AGENTSCOPE_BASE_URL']` 降级读取，并调用 `.rstrip('/')` 防止路径拼接出现双斜杠。
- SSE 流式消息使用 `send_message(..., callback=...)` 模式：每条 `event:`/`data:` 行解析为一个 dict 后通过回调推送到调用方，并在收到 `type == 'done'` 时关闭连接，避免全量缓冲。
- 测试全部基于 unittest.TestCase + `@patch('...requests.*')` mock 外部 HTTP 调用，断言聚焦返回值结构与异常分支覆盖，不使用任何实际网络请求。
- 核心业务逻辑被拆到独立模块文件（project/chat/session/agent/knowledge/upload），CLI 仅做参数绑定与渲染，新增命令无需修改共享后端代码。
