- 所有可序列化的配置 DTO 统一使用 Lombok `@Getter/@Setter` 或 `@Data/@NoArgsConstructor/@AllArgsConstructor/@Builder` 声明字段与构造器。
- 已废弃字段/内部类（如 v1 RAG、`LongTermMemoryConfig`）通过 Lombok 组合 `@Deprecated(forRemoval = true)` 标注以引导迁移到 Harness MemoryConfig。
- `HandoffTrigger`、`LoopConfig`、`SubAgentConfig`、`StateConfig`、`HarnessConfig.*` 等轻量配置对象保持纯数据 POJO 形态，不含业务方法，便于 YAML 直接映射。
- `AgentConfigService` 在 `init()` 中集中完成 YAML 反序列化与去重处理，并通过 `getAgentConfig` / `findAgentConfig` / `getAllAgents` 统一对外暴露只读访问接口。
- `AgentFactory` 中的 agent 创建 API 成对出现：无权限模式（`createAgent`/`createAgentForSession`）与带 `ApprovalMiddleware`/`PermissionMode` 的模式（`buildAgentWithPermission`），由不同重载决定是否注入审批中间件与权限上下文。
