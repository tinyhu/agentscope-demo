根 `pom.xml` 通过 `${agentscope.version}` 集中声明所有 AgentScope starter（core/harness/a2a/agui/channel-feishu/redis/mysql/postgresql/rag-simple/memory-bailian/dashscope），由 Spring Boot profile（`application-a2a.yml` / `application-agui.yml` / `application-feishu.yml` / `application-mysql.yml` / `application-postgresql.yml` / `application-redis.yml`）按需激活对应扩展；Java 侧按职责拆分子包：`agent`（配置模型）、`runtime`（Loop/Parallel/Sequential/MultiAgent/StateGraph 等 `*Runtime` 实现 `AgentRuntime` 接口）、`blackboard`（Supervisor + Expert 路由）、`composite`（图编排示例）、`middleware`（审批/审计/限流等横切）、`mcp`（工具服务桥接）、`tool`（文档解析/搜索等具体工具）、`service`（会话/知识/工作流业务层）、`controller`（HTTP/Feishu/AG-UI/A2A 端点）、`harness`（外部 Harness 适配）、`hook`（可观测性钩子）、`permission`（权限上下文）。Python 侧 `agent-harness/` 作为独立 CLI 客户端，通过 HTTP/SSE 与 Java 后端协作，共享 `skills/cli-anything-agentscope/SKILL.md` 作为技能契约；前端静态资源经 `ChatController` 暴露，SSE 事件由 `AgentEventMapper` 映射到 `ChatEvent` 统一推送。
