- AgentScope 各扩展依赖在 pom.xml 中以 `${agentscope.version}` 统一管理版本，新增协议或存储后端时同步提升该属性而非硬编码版本号。
- 可选能力（A2A、AG-UI、飞书、分布式状态存储）通过 Spring profile + 独立 `application-*.yml` 文件进行条件装配，避免默认启动引入无关依赖。
- 运行时编排类集中在 `runtime` 包，每个编排模式（Loop/Parallel/Sequential/StateGraph/SubAgent*）对应一个 `*Runtime.java` 实现 `AgentRuntime` 接口。
- 中间件采用 `MiddlewareRegistry` 注册表 + 独立 `*Middleware.java` 实现，审批、审计、限流、指标采集等横切逻辑统一挂载。
- Skill 定义遵循 `SKILL.md` + `knowledge/` + `skills/*/SKILL.md` 的文件布局，Java 侧通过 `ClasspathSkillRepository` 扫描加载。
- 测试覆盖遵循 JaCoCo 规则（指令覆盖率 ≥ 60%），配置类与常量类被显式排除在覆盖率统计之外。
